# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project Overview

This is the **ClaudeCode Labcamp Project** - a hands-on learning environment for practicing Claude Code workflows and enhancing daily software engineering productivity. The repository is designed for building repeatable workflows and verification patterns.

## Development Environment

### Python Setup
- **Python Version**: 3.14.0
- **Virtual Environment**: `claudecodeenv/` (already created)
- The virtual environment is gitignored

### Activating the Environment
```bash
source claudecodeenv/bin/activate
```

### Deactivating the Environment
```bash
deactivate
```

### Installing Dependencies
If a requirements.txt is added:
```bash
pip install -r requirements.txt
```

## Git Workflow

- **Main Branch**: `main`
- **Feature Branch**: Work is tracked on `feature/lab-work` branch
- Changes should be committed and pushed to `feature/lab-work` after each meaningful update
- GitHub Repository: https://github.com/StormAIDE/ClaudeCodeLabCamp.git
